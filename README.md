Trabalho prático desenvolvido para a disciplina de Ciência de Dados.

## Estrutura do Projeto
- `dados/`: Datasets do projeto.
- `notebooks/`: Notebooks Jupyter com as etapas de análise e modelos.
- `src/`: Scripts Python para execução das predições.
- `modelos/`: Arquivos dos modelos treinados.
- `outputs/`: Gráficos e resultados gerados.

## Como Executar
1. Instalar as dependências:
   `pip install -r requirements.txt`

2. Executar os notebooks da pasta `notebooks/` na ordem numérica.
